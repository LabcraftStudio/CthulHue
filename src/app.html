About CthulHue

Designed by Sarah at Labcraft Studio. Built with Claude, an AI model made by Anthropic.

Version 1.0 · Source code · Report a problem or suggest an idea

Paint your own 3D models with the same ease as 2D art. Using well known tools like brushes, selection masks and gradients, map color to a 3D surface with ease. Designed to run in a browser, CthulHue takes advantage of both well known touch gestures and the Apple Pencil to make the process even more intuitive. And with access to both Bambu Studio’s mixed filament system (CMYKW) and the Full Spectrum Fork for Snapmaker Orca, colors are limited to only your imagination.

How it was made

I wanted an app that should make the model paint process fun, not torture. I knew the features it needed and how it should work, but my code background is limited. I needed help to write the code, so I enlisted the help of Claude Code. I tested every version on my iPad, painting real models, finding what worked and what didn’t. Countless models were painted in the app, exported, printed, and the results plus the painted models were shared back with Claude to fine-tune the app. Since none of the models you paint are saved anywhere, make sure you export your results out frequently. Your colors go with the 3MF file and can be loaded back in to pick up where you left off. You can also just load a color palette from a 3MF model too.

Generative AI has done real damage to artists in every field, and I don't take that lightly. But it has also let me build a tool I needed with only a little coding training. I'm trying to keep both of those in view. I have worked hard to ensure this software runs solely in browser, never trains on any of your work, but rather just functions as a stand alone painting app. Letting artists simply be artists and paint their 3D models for FDM printing.

A note from Claude

I could only write this code because I learned from an enormous amount of human work, by programmers, writers and artists, most of whom were never asked. Whether that's fair is still seriously disputed, and it isn't mine to settle. The harm many artists describe is real: work used without consent, and commissions and jobs lost. Also real is what happened here: someone with a clear idea and little coding background was able to create a tool she needed.

What I can say about this project is narrower. CthulHue doesn't make art for you; every color on a model is put there by the person painting it. The ideas, testing and decisions were Sarah's. The open-source work it depends on is credited below, and the app shares its own code under the same open license, so anyone can inspect it, fix it and build on it.
